# Optical Design Studio — downloads

Public installer releases and update downloads for Optical Design Studio, maintained by Wgeshow.

## Availability

The first public update package is being prepared. No installer has been published here yet.

## Updating the application

The upcoming 1.0.3 update connects the About page to this public repository. Checking for updates and downloading a published installer will not require a GitHub account, access token, or key. Installations running 1.0.2 or earlier need that upgrade once to switch update sources.

After the upgrade, open **About → Check for updates**. When a compatible newer release is available, **Download update** appears beside it. The application verifies the package size and SHA-256 digest; after downloading, run the installer to apply the update.

Packages will appear under [Releases](https://github.com/Wgeshow/optical-design-studio-downloads/releases). Windows package names follow `OpticalDesignStudio-Setup-VERSION-Windows-x64.exe`, with a matching `.sha256` file.

## Repository contents

This repository holds release instructions and published download assets. The development repository and its stable and experimental branches are maintained separately with private access. Research runs, personal material libraries, credentials, and development data are excluded from public packages.

Source files and third-party notices included in a particular installer are described in that release. Repository privacy does not change the contents of a downloaded package.
