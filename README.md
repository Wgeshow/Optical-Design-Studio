# Optical Design Studio 1.2.0

Optical Design Studio provides optical simulation, structure editing, material
management, optimization, and CAD/COMSOL export. Version 1.2.0 includes optional
version-matched GPU, CAD, and managed MEEP FDTD add-on support.

This is the reviewed readable source for the Windows x64 application. Application
Python files are taken from the verified frozen-build snapshot. User research,
saved libraries, credentials, and machine-local settings are excluded.

See src/README.md and packaging/BUILDING.md for application and build information.
Third-party components retain their individual licenses; see
src/third-party-licenses and src/S4-source/COPYING.
