# Optical Design Studio — downloads

Public installer releases and update downloads for Optical Design Studio, maintained by Wgeshow.

## Download

[Download Optical Design Studio 1.0.3 for Windows x64](https://github.com/Wgeshow/optical-design-studio-downloads/releases/tag/v1.0.3). The release includes the offline installer and its SHA-256 checksum.

## Updating the application

Version 1.0.3 connects About to this public repository. Checking for updates and downloading an installer requires no GitHub account, token, or key. Installations running 1.0.2 or earlier need the 1.0.3 installer once to switch update sources.

After upgrading, open **About → Check for updates**. When a compatible newer stable release is available, **Download update** appears beside it. The app verifies the package size and SHA-256 digest. Run the downloaded installer to apply the update; saved projects, results and materials are preserved. Installation is not automatic.

Packages appear under [Releases](https://github.com/Wgeshow/optical-design-studio-downloads/releases). Windows package names follow `OpticalDesignStudio-Setup-VERSION-Windows-x64.exe`, with a matching `.sha256` file.

## Repository contents

This repository holds release instructions and download assets. The development repository and its stable `main` and experimental `test` branches remain private. The 1.0.3 installer includes readable application/native source and dependency notices. Research runs, personal material libraries, credentials, and saved sessions are excluded from the installer.

The public update check and full installer download were verified without authorization headers or cookies, and the downloaded installer matched the published SHA-256.
