## Sampling calculation and derivation

For a cell with lateral periods Lx and Ly, divide each lateral axis into N equal intervals. Sampling at their midpoints gives x_i=Lx[(i+1/2)/N−1/2] and y_j=Ly[(j+1/2)/N−1/2], for i,j=0,…,N−1. For a finite layer with upper coordinate z0 and thickness d, divide its thickness into D intervals for volume sampling: z_k=z0+d(k+1/2)/D, k=0,…,D−1. Coordinates stored in µm convert to SI metres by multiplying by 10⁻⁶. N and D are dimensionless counts.

The XY map samples the selected layer at z=z0+d/2 using N² lateral points. The XZ map uses y=0, N lateral points, and N depth midpoints in each finite layer. Thus D controls volume sampling, while N also controls XZ depth sampling. With both maps enabled and one finite layer, the saved count is N²D+N²+N²=N²(D+2): 25²(9+2)=6,875 and 49²(17+2)=45,619. This is sampling of an already computed Fourier solution; increasing these sample counts does not increase the Fourier basis.

For normalized complex electric components, E2=|Ex|²+|Ey|²+|Ez|², so the total amplitude is sqrt(E2); a selected component amplitude is |Ei|. The plotted logarithmic value is log10(max(amplitude,10⁻¹⁶)), where the positive floor prevents log(0). This is a display operation on normalized fields, not an SI irradiance calibration. The time-averaged Poynting expression is S=(1/2)Re(E×H*); the accompanying aggregate explains its phasor convention and numerical comparison limits.

Implementation: `src/field_solver.py:_sampling_layout` and `src/qt_compute.py:FieldsPage`, `field_figure`. The [S4 units](https://web.stanford.edu/group/fan/S4/units.html) and [S4 Python API](https://web.stanford.edu/group/fan/S4/python_api.html) document the underlying normalization. Midpoint grids with different counts need not share coordinates. Compare actual common coordinates, or explicitly describe interpolation; do not subtract unrelated rows or infer convergence from a finer-looking plot.

## Optical fields: three alpha.4 driven-field calculations

### Authored system and normalization

The three native runs used a manually authored periodic `1×1 µm` cell, a `0.5 µm` dielectric slab (`n=3.464102`, `k=0`), one centered air circle (`r=0.2 µm`), and air on both sides. At `λ=3001.666667 nm`, illumination was normal-incidence s polarization, `φ=0`. The runs were executed in the alpha.4 native session (source commit `37a8dea74b9a897ee011d98ff7d03f301304bb23`); this provenance is from the owned launch/session record, because the field NPZ/CSV does not embed the application version.

Outputs are normalized complex phasors, not calibrated V/m or W/m². For each sample, `E²=|E_x|²+|E_y|²+|E_z|²`; the stored Poynting vector is `S=(1/2)Re(E×H*)`. With normal s incidence at `φ=0`, incident E points along `+y` and H along `−x`. No physical incident-power scale is inferred.

### Governing field equations and sampling

The optical calculation is a periodic-layer rigorous coupled-wave analysis (RCWA) using S4: Maxwell phasors are expanded in in-plane reciprocal-lattice Fourier harmonics, layer eigenfields are solved, and tangential fields are matched across layer interfaces. With the `e^(−iωt)` convention and nonmagnetic materials, the normalized equations are `∇×E=i k0 H` and `∇×H=−i k0 εE`, where `k0=2π/λ` (the implementation uses S4 lattice-normalized coordinates). A finite reciprocal basis makes the results basis-sensitive; this is not an infinite Fourier solution. See the primary [S4 SetExcitationPlanewave API](https://web.stanford.edu/group/fan/S4/python_api.html#S4.Simulation.SetExcitationPlanewave), [S4 GetFields API](https://web.stanford.edu/group/fan/S4/python_api.html#S4.Simulation.GetFields), and [S4 units](https://web.stanford.edu/group/fan/S4/units.html).

For lateral count `N` and depth count `D`, stored volume coordinates are `x_i,y_i=((i+1/2)/N−1/2) µm` and `z_k=0.5(k+1/2)/D µm`; the XY plane is at `z=0.25 µm`; XZ uses `y=0` and `z_j=0.5(j+1/2)/N µm`, so its depth sampling follows lateral count `N`, not volume-depth count `D`. Thus 25/9 has `25²·9=5,625` volume points, while 49/17 has `49²·17=40,817`; each plane has `N²` points. The archive stores normalized Cartesian complex phasors. The derived intensity-like quantity is `E²=E·E*=Σ_j|E_j|²`; time-averaged phasor flux is `S=(1/2)Re(E×H*)`. These would have units V²/m² and W/m² for calibrated SI phasors, but the unit-amplitude values here remain normalized; no absolute V/m or W/m² calibration is claimed. The factor 1/2 is for peak-amplitude phasors.

The 25/9 and 49/17 midpoint grids are **nonnested**. Exactly one point per volume/XY/XZ group is common: `(x,y,z)=(0,0,0.25 µm)`, where saved complex fields agree exactly. No interpolation was used.
