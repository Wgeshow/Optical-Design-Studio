Optical Design Studio
User Guide

Choose Device Studio for editable finite devices and Optical / Electrical / Coupled simulations, or Original Optical Studio for the original periodic layer/region controls. Both interfaces share projects, settings and the saved library. This guide follows the native Help topics; the preserved Silicon tutorial documents the original optical workflow.

The Silicon example is a real saved production S4 calculation with explicit constant-index approximations. Geometry screenshots show applied inputs; spectrum and field images show the recorded calculation. Changing inputs requires new results.

Device Studio quick start

  1. Choose Device Studio. Create or open a project; inspect the actual loaded structure rather than assuming the illustrative silicon device is loaded.
  2. In Structure, set the finite device dimensions, add enabled layers and assign electrical materials. Edit thickness and donor/acceptor densities. Draw physical regions or voids, add contacts, then Apply selected object.
  3. For a PC region, open Photonic-crystal area…; set its own size and center, unit-cell spacing and hole radius. Inspect the generated count and unused margins before applying.
  4. In Materials, review Electrical definitions and Optical n/k separately. Assign actual optical data before an optical or coupled run.
  5. In Simulation choose Optical, Electrical or Coupled. Complete the setup tabs, Validate setup, resolve blocking issues, then Run. Electrical-only needs a finite mesh and contacts; Optical-only does not require an electrical solve.
  6. Open Results. Choose the saved run and inspect its measured/calculated quantities, inputs and checks. Export the full data when needed.

Changes to a shared Optical or Electrical setup are also used when Coupled composes its next job. Preview geometry contains no calculated fields. Saved results use their saved snapshot, not later edits.

Editable device structure

Device Studio → Structure contains the device tree, linked Top XY / Cross-section XZ / 3D previews, and the selected-object inspector. Device width/depth define the full finite footprint. Layers have thickness, material, enabled state and donor/acceptor concentrations; reorder, duplicate or remove them using the structure actions.

Draw rectangles, circles, ellipses, polygons and square rings. Choose Material override or Void / subtract and the parent layer, then Apply selected object. In this finite-device inspector, Full width / diameter is a diameter for a circle; the original optical region table instead stores circle radius. The PC-area dialog explicitly asks for hole radius. Read the label when transferring dimensions.

Polygon vertices are x/y pairs in µm. Square rings have separate inner and outer dimensions. Later regions override earlier overlapping regions. Local doping regions override the parent layer's donor/acceptor values in their footprint. Disabled physical objects are excluded; camera, color and preview controls only affect display.

Contacts require a stable layer/surface attachment, footprint, boundary and base voltage. An ohmic boundary supplies the supported carrier reservoir; a fixed-potential electrode is a field boundary. Exposed top/bottom/side faces must be resolved by the finite mesh. An electrical contact remains ideal; optional exterior top/bottom optical material and thickness create a scattering pad in S4. A named Au contact alone is not an optical reflector. Review contacts and mesh.

PC area and automatic air holes

The Photonic-crystal area… dialog defines a patterned rectangle independently of the device outline. Set area width/depth and center, cell width/depth and hole radius. The preview reports complete cells, total holes and unused edge margins. Applying creates the full set of editable holes; it does not replace the area by one representative hole.

For a 150 µm device with a 100 µm PC area, cells fill the 100 µm region. At 0.45 µm square spacing, 222 × 222 complete cells fit: 49,284 holes, with the remaining margin split between both sides. Arbitrary area, pitch, center and radius can be edited subject to the geometry/document limits.

Individual holes can be moved, resized, disabled or removed. Reapplying that PC area's fill replaces its generated members; inspect the count before applying. Pattern array… is the separate manual count/pitch tool. Dense previews may sample labels/drawn holes for speed; physical geometry and export retain the full document.

Optical selected cell is a different choice. Use PC lattice size copies the spacing and an existing hole near the PC center; it does not resize the finite device or the PC region. S4 repeats the selected optical cell. Turning selection off retains the full-footprint supercell choice for custom designs without an active PC area. PC-area optical runs use one PC-pitch cell with one air hole; neither workflow provides isolated finite-device optics. Electrical fields and terminal curves keep the full footprint.

For PC-area optical runs, Device Studio defaults to one pitch cell with one actual air hole when no optical cell is configured. Explicit full-footprint or oversized PC settings are retained, with a Domain & solver validation action before Optical/Coupled launch. Original Optical Studio also uses one PC-pitch cell from its table patterns, without canonical contact pads or polygon additions. Other custom periodic designs retain their existing domain choices.

Device geometry and studio lighting

Use the linked top, XZ section and 3D geometry views before a run. Selection identifies the same canonical object in the inspector; changing Section y moves the cross-section cut. Drag the 3D view to orbit and use its zoom/fit controls.

The 3D view menu provides Studio lighting, Soft shadows, Surface reflections, and Hole and edge shading. These improve the preview's surface shading, metal finish and hole walls. They are display effects, not calculated optical scattering, illumination intensity or electric fields.

Fit thin-film display proportions makes thin layers visible. Use equal physical axis scales when judging proportions; use labeled dimensions for lengths. Camera, shadows, reflections, colors and preview opacity do not change geometry, materials or solver inputs. Results field views have their own saved samples and normalization.

Optical setup tabs

Device Studio → Simulation → Optical runs optical calculations independently of electrical charge. The seven sections are:

  1. Overview: choose the study, review the domain and requested outputs.
  2. Domain & solver: choose the selected periodic cell or full-footprint periodic supercell; edit cell width/depth/center and inspect excluded/clipped patterns. S4 always repeats a cell.
  3. Incident light: set s / p / 45° s+p polarization, incidence θ and azimuth φ. s is perpendicular to the incidence plane; p is in it.
  4. Wavelength / angle sweep: choose single wavelength, wavelength sweep or angle sweep. Set only the applicable ranges, positive steps and fixed wavelength; inspect the actual sample count and last grid sample.
  5. Materials & dispersion: inspect real assignments, dataset coverage and per-material interpolation. Static electrical permittivity is not optical n/k.
  6. Accuracy & execution: set Fourier basis, CPU/GPU backend, workers, threads, chunks, timeout and supported diagnostics. Refinement requires actual comparison runs.
  7. Outputs: choose Spectrum only, Spectrum then requested optical fields, or Optical fields only. Set optical field sampling and manual/extremum wavelength selection; a saved-spectrum choice must match the prepared setup. Measure phase saves specular phase during a spectrum stage.

R/T/A are mandatory for a spectrum stage; a fields-only action does not create a new spectrum. Spectrum then fields saves separate stage results: a field-stage error does not erase a completed spectrum. New FDTD solver implementation is outside this update; existing optional Meep controls retain their existing runtime and geometry restrictions.

Electrical setup tabs

Device Studio → Simulation → Electrical runs the finite-device calculation without queuing optics. The seven sections are:

  1. Overview: choose Editable device from Structure or an explicitly fixed legacy study; inspect the actual device and study scope.
  2. Study & bias sweep: choose the swept contact and electrostatic/I–V/C–V study; apply a start/stop/step or manual voltage list. Zero sweep offset is included as the reference. The swept contact receives base voltage + offset; other contacts keep their base voltages.
  3. Contacts & boundaries: edit enabled contacts, base voltages and ohmic/fixed-potential boundaries; inspect the attachment and footprint before solving.
  4. Materials & doping: assign electrical materials, edit donor/acceptor densities and local doping regions, and inspect evaluated parameters/source notes.
  5. Temperature & charge: set the device temperature and semiconductor Fermi–Dirac Poisson or charge-free dielectric/Laplace mode. Charge-free mode ignores stored mobile carriers and dopants.
  6. Finite device mesh: set Nx, Ny, depth cells per enabled layer and the cell budget. Preview actual coverage of shapes and exposed contact faces; the optical cell never crops this mesh.
  7. Outputs & measured data: enable I–V/C–V, select the initial saved-result view, and import optional measured curves with explicit units.

The editable solver supports equilibrium/reverse-biased prescribed reservoirs. Forward-biased p/n reservoirs and conflicting same-carrier reservoir voltages are blocked because continuity/transport is absent. Electrical-only can run with an incomplete optical draft. Fixed legacy study choices keep their own geometry, doping, temperature and runtime limits; they do not adopt arbitrary editable geometry.

Coupled setup tabs

Device Studio → Simulation → Coupled composes the active shared Electrical and Optical settings. The six sections are:

  1. Overview: review both setups, the reference, resolved state/sample counts and supported outputs.
  2. Electrical setup: use the complete shared electrical editor. Edits also appear in standalone Electrical; the active Run action remains Coupled.
  3. Optical setup: use the complete shared optical editor. Edits also appear in standalone Optical; Return to transfer brings you back to mapping.
  4. Transfer & mapping: choose zero-bias or undoped optical reference, map stable electrical layer IDs to matching optical layers, and set optical depth slices. Selected-cell carrier averages use solid-only areas and fractional mesh-cell overlap weights.
  5. Response tracking: choose R/T/A, Peak/Dip, reference wavelength and tracking window. Features are sampled local features; missing features stay unavailable.
  6. Outputs & checks: review electrical volumes, spectra, index profiles, response features and optional shared I–V/C–V flags.

Run order is finite Electrical → carrier/material transfer → periodic S4 spectra at the bias states → saved Results. Optical slicing does not refine the electrical mesh. Matching thickness, order, optical data and mapping are checked before launch. Mixed solid materials in one layer are blocked for coupling until material-specific averages are supported; electrical-only remains usable.

Carrier Drude corrections use editable masses and mobilities. Optional electro-optic/interband corrections are restricted to their supported GaAs conditions, not silently applied to silicon. Shared standalone optical phase/E/H requests are preserved but are not generated by the coupled backend. Select supported coupled outputs explicitly, or require all requests and resolve the blocking issue. Run standalone Optical for those outputs.

Electrical materials and custom definitions

Materials → Electrical contains editable GaAs, ITO, AlGaAs, Silicon and Air/void definitions. Select a material to compare saved reference properties with values evaluated at temperature. Review Sources, assumptions and overrides; Add custom, Duplicate, Import JSON and Export JSON use stable material IDs.

Properties include static εr, band gap, electron affinity, conduction/valence density of states, conductivity/DOS effective masses, mobilities, intrinsic density, optional bulk carrier populations and explicit fixed conductivity. Concentrations use cm⁻³, mobilities cm²/(V·s), conductivity S/m, energies eV and temperature K. A conductivity override of exactly zero remains an open circuit.

GaAs/AlGaAs use Ioffe reference models; Silicon uses the Colorado parameter sheet and the recorded silicon temperature/affinity sources. AlGaAs alloy fraction is editable. Reference laws can update gap/DOS/intrinsic density while explicit edits remain overrides. Bulk mobility defaults are constants, not a fit to every doping or field.

ITO preset density, mobility, static permittivity, mass, affinity and gap are explicitly starting model assumptions; AlGaAs transport values are estimates. Replace them with sample-specific values when needed. Optical material names link to actual project n/k datasets; optional constant n/k is an explicit approximation. Static εr is never treated as optical ε. Missing optical assignment blocks Optical/Coupled without preventing an electrical-only job.

I–V and C–V

In Electrical → Study & bias sweep or Outputs & measured data choose I–V, C–V or both. Coupled uses the same flags. Set the swept contact and base voltages first, then apply the voltage offsets.

I–V is a frozen-conductivity Ohmic estimate. It uses zero-offset carrier populations and σ=q(nμn+pμp), unless an explicit conductivity override is supplied, including zero. It saves currents and conservation/power checks. It does not predict diode junction transport, injection, leakage, recombination or contact resistance.

C–V is a signed electrostatic electrode-charge derivative dQ/dV. It differentiates saved displacement charge at the swept electrode with all other terminal voltages fixed. At least three distinct bias states are required. Endpoint derivatives are one-sided; negative signed capacitance is preserved. It does not add transported reservoir charge or AC frequency/trap dynamics.

Measured comparisons use CSV columns bias_V,current_A or bias_V,capacitance_F. They are labeled measured overlays and do not replace computed data or automatically fit the material. Refine mesh and voltage spacing before treating either estimate as quantitatively converged.

Results → I–V / C–V displays the actual saved studies. Unrequested or missing curves remain unavailable. Saved results and exports.

Results: saved runs, optical fields and phase

Open Results and choose a saved run. Loading results inspects its immutable inputs and data without replacing the current editor. Restore/load setup is an explicit separate action. Available categories reflect saved files: Overview, Potential & fields, Carriers & charge, Energy bands, Optical response, I–V / C–V, Mesh & convergence, Inputs & materials, Raw data & exports, Optical E/H and Specular phase.

Electrical potential/DC fields and carriers use the selected saved bias volume. Linked XY/XZ/3D probes snap to actual stored coordinates and identify the material/layer/contact where saved. Geometry view colors and display sampling do not alter complete exports. Mesh/residual/charge checks describe that run; a successful solve alone is not a mesh-convergence study.

Optical E/H opens a genuine field-only result even without results.csv. Choose the saved wavelength/angle sample, quantity and layer; inspect XY / XZ maps, 3D E/H playback and saved samples. Ex/Ey/Ez and Hx/Hy/Hz are complex electromagnetic amplitudes with their recorded S4 normalization; they are not electrical DC fields in V/m. Playback animates steady-state harmonic phase, not pulse propagation.

Specular phase reads actual saved reflection/transmission phase. It cannot be recovered from R/T/A power alone. Zero-signal/undefined phase remains unavailable. Spectrum then fields links the completed spectrum and its separate optical-field stage; partial or failed stages retain their actual status.

Export CSV / NPZ opens the relevant saved-data actions: complete electrical grid, original volume NPZ, optical selected-sample CSV/NPZ, full response/terminal CSVs or complete phase CSV. Export VTK applies to saved electrical volumes; figure exports use the selected actual plot. Open run folder and run/library archives retain input snapshots and provenance. On-screen row/point limits do not truncate complete exports.

Setup presets and validation

Simulation → Save setup writes a named Optical, Electrical, Coupled or all-settings preset. Load preset previews changes before applying. A preset changes configuration while retaining the current finite geometry; referenced contacts and mappings must resolve to current stable IDs. A setup preset is separate from a portable project, which also includes geometry and material definitions.

Each valid edit commits through the shared project. Invalid typed values remain visible drafts with errors instead of silently becoming a numeric default. Switching modes keeps those drafts; standalone Optical checks its relevant settings, Electrical checks electrical settings, and Coupled checks both.

Validate setup resolves the real domain/materials/options and reports blocking issues with their edit sections. Fix the indicated tab, then validate again. Run uses the applied snapshot and starts without an extra simulation confirmation. A busy application blocks a second calculation; Stop requests cancellation and saved results show whether work completed, failed or was interrupted.

Validation checks representability and numerical inputs. Fourier-basis, spatial-mesh, voltage-step and wavelength convergence require actual comparison runs; a preview or Ready status does not establish them.

Launch, storage and upgrades

Windows portable release

Extract the complete OpticalDesignStudio-Portable-1.3.2-Windows-x64.zip to a writable folder, then run Optical Design Studio.exe. Keep OpticalDesignBackend.exe and _internal beside it. The complete portable package includes Python and the calculation runtime; a separate Python installation is not required.

This release is unsigned. SHA-256 checksums identify archive contents and check download integrity; they are not a publisher signature. Keep the supplied notices and source when redistributing included components.

Run from source

The separate corresponding-source archive requires a compatible 64-bit Python 3.12 environment, its pinned dependencies, and an S4 native extension built for the same platform and Python ABI. From the archive root, run python .\src\qt_app.py; from its src directory use launch_qt_gui.cmd. Set S4_PYTHON to the intended interpreter when using a launcher. See README.md and DESKTOP_GUIDE.md for dependencies and source setup. Source is not a substitute for the complete portable runtime.

Preserve your work

Save projects, finish calculations and close the old application before updating. Back up saved project JSON files and the active data directory shown in Settings → Data storage. A default portable installation uses User Data beside the executables. When using a new program folder, preserve that folder; extraction does not move an existing library. Preserve a custom data directory and its portable_settings.json selection, then confirm the active location after launch. Help → Quick actions → Open library folder opens the current library.

Meep, GPU, CAD and machine-learning features have their own documented runtime requirements. The desktop can use CPU S4 without installing the optional Meep engine. Use Help → About to confirm the running version; Help → Updates checks the configured release source.

First simulation: Silicon on SiO₂

For these exact controls choose Original Optical Studio at startup. The saved example and its verified result files remain available from either workspace.

This walkthrough uses the bundled Silicon example, which also has genuine saved S4 results. Geometry: Air above, a 220 nm Silicon film, semi-infinite SiO₂ below, one centered circular Air hole with 100 nm radius, and a 540 nm square period. The radius corresponds to a 200 nm diameter. Silicon n = 3.48, SiO₂ n = 1.45 and Air n = 1; k = 0. These are explicit constant-index tutorial approximations.

  1. In Help → Quick actions, choose Open example project, or open the portable example JSON. Save a personal project copy before editing.
  2. In Structure, choose Silicon in the named Layer dropdown. Confirm the film thickness, lattice and Air region. Layer selection follows the stack and 3D selection. Apply layer, lattice or pattern after edits.
  3. In Materials, inspect Silicon and SiO₂. Confirm that the constant optical models are intentional approximations. Display color and preview opacity change geometry appearance only.
  4. In Settings → Performance, use CPU computation and set the requested Fourier basis to 81 to reproduce the recorded run.
  5. In Simulation → S4 · RCWA, use wavelength mode: start 1515 nm, stop 1555 nm, step 1 nm, p polarization, θ = 0° and φ = 0°. Check the selected field-sampling controls before running; the recorded example used 25 samples per axis and three volume depths in the finite Silicon layer.
  6. Use the fixed bottom Run control. Inspect the 41 calculated spectrum samples and saved fields. Changing the geometry requires a new calculation; old results keep their original input snapshot.
  7. For the illustrated field maps, use the saved 1550 nm sample. XY is z = 0.11 µm inside Silicon; XZ is y = 0 through the film. Inspect normalization and physical coordinate labels.
  8. Export complete CSV files or open the saved run directory. Increase basis and refine wavelength/grid/depth sampling before treating an optical feature as converged.

The saved lossless spectrum has R + T near one and negligible absorption within numerical precision. This smooth tutorial spectrum does not establish a resonance, experimental material accuracy or spatial-field convergence. The recorded basis comparison is evidence for this example and these settings.

To inspect the completed calculation without running it again, open the actual-result topic below. Its CSV files, inputs, all 41 field datasets, basis comparisons and provenance are shipped beside the images.

Structure and layers

Original Optical Studio controls. For the new finite-device workflow, see Device Studio quick start.

Select a stack layer or choose its name from the Layer dropdown. Edit name, material and finite thickness, then Apply layer before switching layers or running a calculation. Add above / below inserts using the current form; Duplicate copies regions; Move up / down changes finite-layer order; Delete removes its regions too.

The first and last layers are semi-infinite incident and exit media. Their stored thickness is zero; the preview displays only finite padding. Materials

Search project materials or saved presets. Inspect n / k, source and covered wavelengths. Apply material to layer assigns the selected entry; a preset is added to the project when needed. Removing a project material does not remove its saved preset, and a material used by geometry cannot be removed.

Constant n,k is an explicit approximation. A tabulated dataset has wavelength dependence; solver requests must stay inside its covered band. With the passive sign convention, k describes attenuation and ε=(n+ik)². Do not replace a dispersive dataset with a constant merely to bypass a coverage error.

Record the dataset page, publication, sample conditions and wavelength units. Save a named preset for future projects; prior saved versions are retained. Export optical constants CSV uses the selected real dataset.

Project / Library / All scopes filter the searchable material cards. Choose n & k, n only or k only above the graph. Dots show original table samples; the curve evaluates the selected interpolation between them. The data table and complete CSV retain original samples.

Linear interpolates n and k linearly. Linear (in log k) keeps n linear and interpolates log(k); every k sample must be strictly positive. This policy affects S4 optical constants and MEEP dispersion fitting and is saved with the project and library preset. Constant models have no wavelength interpolation.

Display color and Preview opacity affect the material's geometry preview only; explicit layer colors take priority. Notes preserve exact multiline project text and can be saved with a preset. Source attribution stays separate. Changes autosave; an unsuccessful save retains the notes draft for retry. Apply material to layer assigns real data without changing layer dimensions.

Device Studio also provides the separate Electrical material catalog. See electrical properties and custom definitions; optical n/k and electrical static permittivity are separate inputs.

Electric fields

Original Optical Studio controls. For the new finite-device workflow, see Device Studio quick start.

AI Search

Set up owns wavelength, polarization, angles, basis, field objective and parameter ranges. Structure geometry and Settings computing resources are shared, but Simulation edits do not change AI illumination. Copy ranges is an explicit copy.

The field-confinement objective supports an aligned circular air hole in each selected perforated layer above an unperforated substrate. Troubleshooting

  • Changes not reflected: Apply layer/region edits, confirm the shared structure, and start a new run. Loading a saved result shows its historical snapshot.
  • Material coverage: inspect n/k wavelengths, import unit and intended dataset. Restrict the request to covered data or obtain an appropriate dataset.
  • No phase/fields: enable the relevant measurement before running; power CSV alone cannot reconstruct phase or complex fields.
  • No tracked peak: inspect overlaid spectra, range and search radius. Endpoints and unresolved baseline features produce missing values.
  • GPU unavailable: Check selected runtime, review dependency/device messages, then choose CPU to verify the model. GPU mode names do not prove offloading occurred.
  • Meep unavailable: check Add-ons, published-pack availability, WSL2 and the selected Linux runtime. Source integration does not imply an installed engine.
  • Search cannot qualify: inspect fabrication limits, sampled resolution, held-out errors and higher-accuracy verification. No passing design is a valid outcome.
  • Resume incompatible: restore the campaign settings or start a new campaign. Do not merge mismatched materials/illumination/accuracy.
  • Slow or large results: test a smaller design budget/grid, inspect basis and storage, then restore required accuracy for final work.
  • Old appearance: restart the updated source launcher; an older packaged EXE keeps its own interface.

MEEP FDTD

On Windows, Meep uses a separate managed WSL2 runtime. Settings → Add-ons → Install FDTD engine checks for a matching published pack; opening Settings does not install anything. Set up Windows support can require an administrator prompt and restart. Expert setup validates an existing Linux interpreter.

2D solves an XZ cut extruded along Y: a hole array becomes a grating. Use 3D for the complete periodic unit cell. The supported source is a normal-incidence Gaussian broadband plane pulse with s (Ey) or p (Ex) polarization. X/Y are periodic; depth uses PML. Arbitrary sources, oblique incidence, GPU Meep and MPI are not exposed.

Length uses µm and time µm/c. Frequencies are evenly spaced in inverse µm, so wavelength samples are not uniform. A homogeneous reference simulation precedes the device; reflection subtracts incident Fourier fields and powers normalize to reference transmission.

Check resolution, PML, padding and maximum time. A maximum-time termination produces a convergence warning. Passive tabulated materials require validated dispersion fitting; complex constant index is rejected as a broadband model. Incident/exit media must be constant and lossless. Optional XZ DFT field amplitudes are raw, not incident-normalized. Saved job, fit, summary and worker logs are available with the run.

Δn sweep and carrier density

Choose a project material and check layers to perturb; background and regions using that material in those layers change, while other occurrences and the library stay unchanged. Manual Δn adds a real refractive-index shift and keeps k fixed. Constant ε is first converted to its principal complex refractive index; Δn is not additive ε.

Equal shift uses one shared axis. Independent layer bounds enumerate combinations; equal start/stop with one sample gives a fixed offset. A zero-shift baseline is included at most once. The wavelength range and illumination come from S4 · RCWA; wavelength mode needs at least three samples. There is a limit of 200 requested combinations plus baseline and 200,000 wavelength samples.

Carrier density mode configures reference and biased electron/hole concentrations in cm⁻³ using the carrier dialog. Its material model can change both index and absorption; it is not equivalent to the manual real Δn approximation. Review material parameters and model applicability in the carrier guide.

Choose R/T/A, peak/dip, reference λ and search radius. Tracking locates a sampled local feature near the baseline; endpoints are excluded. Missing features remain blank. Shared sweeps report Δλ/Δn in nm/RIU; independent sweeps do not claim one multi-parameter sensitivity.

Fixed-wavelength Δn readout

The baseline peak/dip selects one locked λ₀. Fixed-wavelength response measures every shifted spectrum at that same baseline sample, even when its resonance moves. Change from baseline is the signed difference; Overlaid spectra shows full curves and λ₀.

Underlying R/T/A are power fractions, not watts. Response plots show percent and baseline-change plots show signed percentage points; a 0.01 fraction change is 1 percentage point. An unresolved baseline feature leaves the readout unavailable. In independent sweeps, select a Δn axis; each curve holds other offsets fixed as recorded in its legend. The UI displays at most 24 curves, but CSV includes every case.

index_shift_spectra.csv retains R/T/A, index_shift_features.csv records sampled feature positions, and index_shift_readout.csv records λ₀, baseline and changes. Tracking does not establish mode identity or sub-sample peak location; inspect crossing/splitting curves and refine wavelength/basis.

Carrier models and depth profiles

The carrier dialog uses absolute reference and biased electron/hole concentrations. Reference-data mode assumes library n/k already include the reference carrier state; Undoped mode adds absolute corrections for both states. Bias voltage is supplied metadata, not a prediction of carrier concentration.

The implemented free-carrier Drude approximation uses explicit conductivity masses and fixed mobilities. Increased carriers lower n and increase loss in this model; depletion reverses the change. Negative resulting k is rejected. GaAs/custom materials are not automatically validated by a silicon model; review source assumptions, editable masses/mobilities and the 1000–2000 nm guard. Concentrations above 10²⁰ cm⁻³ are rejected.

Depth CSV uses layer,z_um,reference_electron_cm3,reference_hole_cm3,electron_cm3,hole_cm3 and covers both endpoints of every selected finite layer. All states use the same depth/reference grid. Duplicate nodes marked side=left then side=right preserve discontinuities. Slice density is evaluated at midpoints; region geometry and total thickness are preserved. Refine slice sampling.

The reported depth-averaged Δn is thickness weighted, not field weighted or modal effective index; spectra use the full sliced model. COMSOL four-file import has explicit layer mapping, units and audited optional negative-noise cleanup. The abrupt-junction estimator assumes a homojunction/depletion model and does not solve transport or automatically generate a profile.

Performance and convergence

Fourier basis controls RCWA accuracy and cost. Increase basis and refine wavelength/grid sampling until the quantity of interest stabilizes. A narrow high-Q feature needs sufficient spectral samples; a search result is not a convergence study.

Settings → Performance chooses CPU/GPU mode, time limit and offload threshold. Check selected runtime performs an actual GPU calculation when a GPU mode is selected. The default threshold 1024 can leave small calculations on CPU; Use GPU for small matrices sets threshold 1 and can be slower. ML fitting uses CPU. Review saved acceleration counts and fallback warnings.

For FDTD converge resolution, PML, padding and termination time separately; hitting maximum time requires review. For field maps refine Fourier basis as well as grid/depth sampling. Comparing different numerical settings is not a material effect.

Silicon example: actual spectrum and fields

These images come from a completed production S4 · RCWA calculation of the bundled example: a 220 nm Silicon layer on semi-infinite SiO₂, with centered circular Air holes of 100 nm radius and a 540 nm square lattice. Air is the incident medium.
